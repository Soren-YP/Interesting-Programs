# AI 痕迹检查清单

原文章的「Technique 7: Remove AI tells」在付费墙之后，下面这份清单是根据文章前文的论点
（AI 选最可能的选项、爱加不爱减、用代码替代图像）和常见 AI 界面特征整理的。
它是检查工具，不是风格规则：某条如果是 brief 里**有意为之**的选择，可以保留，但要能说出理由。

## 构图

- [ ] 首屏是否是"顶部导航 + 左侧栏 + 右侧卡片网格"的默认骨架，且没有任何理由？
- [ ] 所有区块是否都是同样大小、同样圆角、同样阴影的卡片？
- [ ] 是否每个区域都被一个容器 / 边框包起来，层层嵌套？
- [ ] 视觉焦点是否明确？还是所有东西一样响？
- [ ] 留白是均匀撒开的，还是有节奏、有松紧？

## 色彩与表面

- [ ] 紫 / 蓝紫渐变、霓虹光晕、毛玻璃，在没有概念支撑时出现？
- [ ] 用颜色给文字随意高亮，颜色没有承载含义？
- [ ] 用 CSS 渐变、几何形状、噪点纹理代替本该存在的真实图像？
- [ ] 深色模式只是把颜色反转，而不是重新考虑过？

## 字体与文案

- [ ] 字号层级过多，或所有标题都是同一种"粗体 + 大号"？
- [ ] 文字过大、过松，信息密度低于这个场景应有的水平？
- [ ] 界面在解释显而易见的事（"在这里搜索你的收藏""点击按钮以添加"）？
- [ ] 文案是否带着"赋能 / 轻松 / 无缝 / 一站式"这类空洞营销腔？
- [ ] 每个按钮前都挂一个图标，图标没有增加识别度？
- [ ] 用 emoji 充当图标或装饰？

## 组件与交互

- [ ] 自定义的按钮、输入框、下拉、复选框比浏览器原生的更难看或更难用？
- [ ] 所有可点击元素悬停时都是同一种"抬起 + 阴影加深"？
- [ ] 动效是否只是 fade-in / slide-up 的重复，与概念无关？是否拖慢了操作？
- [ ] 徽章、标签、计数器到处都是，却没人需要？
- [ ] 空状态是否只是一个灰色图标加"暂无数据"？

## 最后一问

遮住产品名，把截图和十个 AI 生成的同类界面放在一起——它还能被认出来吗？
如果不能，回到 brief 里的"标志性细节"，确认它真的在界面上出现了。
