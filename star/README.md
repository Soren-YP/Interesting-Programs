# Star 本地收藏夹

Star 是一个本地优先的个人收藏管理与网页入口。收藏、分类、标签和设置保存在当前浏览器的
`localStorage` 中；网页标题读取与链接检查由仅监听 `127.0.0.1` 的本地 Node 服务完成。
界面采用 “构造契约” 设计：被几何构造线标注的个人索引手稿，悬停条目时引出注释，
不依赖在线字体或图标 CDN。设计说明见 `design/brief.md`。

## 环境

- Node.js 22 或更高版本
- npm 10 或更高版本

## 开发与使用

```powershell
npm install
npm run dev
```

开发页面位于 <http://127.0.0.1:5173>。

构建并以本地应用模式运行：

```powershell
npm run build
npm start
```

应用位于 <http://127.0.0.1:4173>。项目使用 ES Modules 和 Service Worker，不保证直接双击
`index.html` 时完整运行。

## 测试

```powershell
npm test
```

测试覆盖数据迁移、导入导出、筛选排序、拖拽顺序、界面交互保护和本地服务安全边界。

## 数据与备份

- 新版数据键：`star.appState.v1`
- 恢复快照键：`star.recovery.v1`
- 首次启动会自动读取旧版 `bookmarks`、`categories` 和 `darkTheme`
- JSON 备份保存收藏、分类和设置
- 浏览器书签 HTML 可与 Chrome、Edge、Firefox 等浏览器交换基础收藏数据
- 单次导入限制为 5 MB、最多 10,000 条收藏

导入时会先展示新增、重复、无效和分类数量。安全合并不会覆盖已有收藏；完整替换会先保存一份
可撤销的恢复快照。

## 隐私和网络

- 应用没有账户、云同步或遥测
- 本地 API 只绑定 `127.0.0.1`，并拒绝非本地网页来源
- 读取网页标题和检查链接时，本机需要直接访问目标网址
- 链接检查只在用户主动触发时运行
- 离线时收藏管理仍可使用，网站图标会回退到本地图标

## 快捷键

- `/` 或 `Ctrl/Cmd + K`：聚焦统一搜索框
- `Enter`：打开网址、首个匹配收藏，或在没有匹配时搜索网页
- `Ctrl/Cmd + Enter`：始终使用所选搜索引擎搜索网页
- `N`：新建收藏
- `Escape`：关闭弹窗或退出批量管理
