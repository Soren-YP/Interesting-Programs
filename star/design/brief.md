# Star 设计 brief · 构造契约

## 一句话概念

**Star 是一张被几何构造线标注的个人索引手稿**：每条收藏都是画面上一个被圈出、编号、可以引出注释的节点。

## 情绪目标

打开时像翻开一份精密而有美术指导的手稿：安静、留白充足、很"贵"，但能看出作者的笔迹。
日常操作（搜索、扫读、打开）必须快而清楚；戏剧性只出现在少数时刻。

## 语言

- **底**：浅灰白（浅色）/ 近黑虚空（深色）。只有黑、白、灰，加**一种群青蓝**。
- **字**：高对比衬线承担展示与条目标题（中文宋体 / 衬线），等宽小字承担标注与元数据，
  无衬线只用于按钮与表单等功能文字。
- **构造图形**：发丝线、点状大圆弧、圆形节点、刻度尺、十字准星、实心编号圆（❶❷❸）、
  竖排字距拉开的小字。
- **姓名戳**：散落在画面边缘的衬线大写字母 **Y A P E N G**，部分镜像、部分半透明重影、
  部分被视口裁切。这是作者的签名，不是装饰文字——不可被读成一行字，也不能抢列表的注意力。
- **半透明平面**：白色（深色模式下为极淡的白）半透明薄片层叠。**每一片的形状、倾角、方向都不同**
  （不同的四边形、梯形、细长条、有的几乎水平、有的陡峭），像散落的纸片和光，而不是重复的斜条纹。

## 明确拒绝

- 第一轮 A / B 那种"工业 HUD / 战术界面"的标签化 UI
- 所有平面同一倾角、同一形状的重复图案
- 渐变、光晕、毛玻璃、圆角卡片网格
- 胶囊形标签、每个按钮都配图标
- 解释显而易见之事的说明文字

## 标志性细节

**标注线**：鼠标悬停或键盘聚焦某条收藏时，它的图标节点被一个圆圈出，一条折线从行尾引到右侧
的注释区，显示完整网址、分类、标签、添加时间和链接状态，末尾是 `OPEN ↵`。
不悬停时，注释区显示当前视图的说明。窄屏不显示注释区。

## 落点

| 时刻 | 表达 |
|---|---|
| 首屏 | 巨大衬线视图名 + 竖排英文 + 等宽元数据；搜索是一条细线加圆形节点 |
| 列表 | 编号、圆形节点里的网站图标、衬线标题、等宽域名、细分隔线；安静、对齐 |
| 悬停 / 聚焦 | 节点被圈出，引出标注线到注释区 |
| 选中（批量） | 节点填充群青 |
| 分类 | 竖向刻度尺，当前项有蓝色长刻度 |
| 视图 | ❶❷❸ 实心编号圆 |
| 弹窗 | 同一套构造语言：细线边框、编号标题、无圆角或极小圆角 |
| 深色 | 参考 2 的黑色虚空：近黑底、白色字、极淡平面、更亮的蓝 |

## 约束

- 所有现有功能保留，`npm test` 与 `npm run build` 通过
- 字体使用本地已安装字体的回退栈，不加载在线字体（正式打包字体是后续工作）
- 动效快（< 250ms），尊重 `prefers-reduced-motion`
