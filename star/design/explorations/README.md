# Discover · 方向探索（2026-11-02）

用户给定的品味参考：**Apple** 与 **鹰角网络（Hypergryph）** 的平面设计语言。

## 从参考中观察到的语言

**鹰角（明日方舟 / 终末地官网）**
- 贯穿整个视口的发丝线框架，像图纸的边框和裁切线
- 等宽小字的信息标注：`>> LOADING - 2%`、`ARKNIGHTS // https://…`、坐标、编号
- 中英双语叠排：英文大写为主标签，中文小字在下（或反之）
- 纯黑实心色块承载关键操作；大面积白 / 深灰底上只出现一种信号色（终末地黄、方舟青）
- 等高线、点阵、十字准星、刻度这类"测量"图形作为底纹
- 粗重的中文标题字配极细的辅助线，反差强烈

**Apple**
- 克制：每屏一个焦点，元素少，留白有节奏
- 精确的网格与对齐，文字层级少而清楚
- 材质与动效服务于操作，不做装饰；感觉"原生"
- 单一强调色，颜色只承载含义

两者的交集：**精密感**。都是在严格的网格上做减法，靠排版和细线而不是装饰取胜。

## 概念清单（宽泛，不求细节）

1. 测绘底图：收藏是地图上的坐标点
2. 设备铭牌：每条收藏是一块带编号的冲压铭牌
3. 出发信息板：打开收藏 = 放行
4. 档案抽屉：分类即抽屉，层级明确
5. 仪表刻度：用刻度尺做筛选和计数
6. 游标卡尺：刻度作为分隔线与进度
7. 安全手册印刷品：编号章节、警示条、双语标签
8. 光学玻璃：Apple 材质，单一焦点
9. 系统偏好面板：极致原生、极致克制
10. 终端引导程序：`>>` 前缀、启动序列
11. 集装箱标识：模板字编号、色块编码
12. 博物馆展签：每条收藏一张展签
13. 点阵晶格：点阵网格做结构和选择指示
14. 物流单据：栏位、撕线、条码
15. 航海图：等高线、方位

# 第二轮（2026-11-02）· 用户提供的参考

用户反馈：第一轮我从鹰角官网截取的参考（终末地首页、方舟加载页）**本人都不太喜欢**。
用户自己挑了三张更能代表其所喜欢的设计语言的截图，存于 `design/references/`：

| 文件 | 画面 | 关键语言 |
|---|---|---|
| `01-blue-shard-typography.webp` | 白底，蓝色剪影人物，"LOOK INTO MY EYES" 沿对角线爆开 | 白色虚空 + **单一饱和群青 / 青色系**；黑色粗重斜体窄字压在对角线上；切片、碎片、斜向色带；线稿被裁进条带；极强的方向性和速度感；大面积留白 |
| `02-marble-void.webp` | 黑底，大理石雕像与碎块悬浮，光环与放射状刀片 | 纯黑白；古典雕塑的**材质与神圣感**；碎片悬浮；放射构图；戏剧性光影 |
| `03-construction-hands.webp` | 浅灰白底，《创造亚当》的两只手被几何构造线标注 | 圆形节点、连线、点状弧线、十字准星、刻度尺、❶❷ 编号；**高对比衬线大字**被镜像、裁切、散落；竖排字距拉开的小字；细蓝线；炭笔 / 墨迹质感；半透明白色平面叠层 |

**共同点**：黑 / 白为底，**只有一种蓝**；排版本身就是画面主角（巨大、旋转、裁切、
衬线与粗黑体混用）；对角线与碎片带来动势；古典意象 × 技术构造线；海报 / 片头级的美术指导。

**与第一轮的差别（否定信息）**：用户喜欢的不是"工业 HUD / 战术界面"那种标签化 UI
（第一轮 A、B 的来源），而是更偏**动态海报、片头美术**的表达。

## 工具型应用如何承载海报级表达

收藏夹每天打开很多次，不能每次都播片头。原则：**戏剧集中在少数时刻，日常操作保持安静精确。**
- 页眉构图（视图名、搜索）——每次打开看到的"海报"
- 打开收藏的瞬间——一道斜向的蓝色切片转场（< 300ms）
- 悬停 / 选中——蓝色斜切色块或构造线标注
- 空状态、导入完成、链接检查——可以更放肆
- 深色模式——参考 2 的黑色虚空
